# The Editor 3D

A web-based 3D editor and game engine built with Three.js.

## Live Demo
You can try the editor online here: [https://wox76.github.io/theeditor/](https://wox76.github.io/theeditor/)

## Features
- 3D Scene management
- Asset loading (GLB/GLTF)
- Integrated Game Manager and Player logic
- Post-processing effects (Pixel Shader)
- Level editing and saving

## Getting Started
Simply open `index.html` in a web browser or visit the live demo link above.
